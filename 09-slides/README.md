# 09 · Презентация за минуту

**Бесплатный аккаунт: ✅ доступно (документы и презентации)** · ⏱ 10 минут

## Зачем

Черновые заметки к выступлению Claude превращает в готовую презентацию или документ. Результат можно отредактировать и скачать как PowerPoint или PDF.

## Задание

1. Откройте файл [`zametki-k-vystupleniyu.md`](zametki-k-vystupleniyu.md) и скопируйте текст в чат.
2. Напишите:

   ```
   Сделай из этих заметок презентацию на 6 слайдов для заседания кафедры. Минимум текста на слайдах, ключевые цифры крупно. На последнем слайде — решения, которые нужно принять.
   ```

3. Попросите правки прямо словами:

   ```
   Слайд 3 сделай в виде схемы из трёх шагов. Добавь слайд с вопросами для обсуждения.
   ```

4. Скачайте результат (кнопка скачивания: PowerPoint или PDF).

## Ещё идеи

- «Сделай из этих заметок служебную записку на одну страницу».
- «Сделай раздаточный материал для студентов: одна страница, крупный шрифт».
