# 03 · Память

**Бесплатный аккаунт: ✅ доступно** · ⏱ 5 минут

## Зачем

Claude может помнить о вас важное между разными чатами: должность, кафедру, предметы, как вы любите получать ответы. Тогда не нужно объяснять это в каждом новом разговоре.

## Как включить

**Настройки (Settings)** → раздел про память → включите генерацию памяти из чатов. Там же можно посмотреть и отредактировать, что Claude запомнил.

## Задание

1. В обычном (не инкогнито) чате напишите, подставив свои данные:

   ```
   Запомни: я преподаю на кафедре информатики ВКУ, веду «Основы программирования» у первокурсников. Ответы мне нужны кратко и по пунктам.
   ```

2. Откройте **новый** чат и спросите:

   ```
   Придумай задание на дом к следующему занятию.
   ```

   Claude учтёт ваш предмет и курс без лишних объяснений.

3. Попробуйте удалить запись:

   ```
   Забудь, что я веду «Основы программирования».
   ```

## Важно знать

- Не просите запомнить ИИН, пароли, номера карт и чужие персональные данные.
- Чаты в проектах имеют свою отдельную память.
- Инкогнито-чаты в память не попадают.
