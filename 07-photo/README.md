# 07 · Фото вместо описания

**Бесплатный аккаунт: ✅ доступно** · ⏱ 5 минут

## Зачем

Не перепечатывайте таблицы, расписания и рукописные заметки вручную. Сфотографируйте или сделайте скриншот, и Claude перенесёт данные в таблицу, переведёт текст или объяснит ошибку на экране.

## Как прикрепить

- На компьютере: скрепка 📎 в поле ввода или перетащите файл в чат.
- На телефоне: **+** → камера или галерея.

## Задание

1. Скачайте учебное фото [`vedomost.png`](vedomost.png) из этой папки (или сфотографируйте его с экрана).
2. Прикрепите его в чат и напишите:

   ```
   Перенеси данные с фото в таблицу: ФИО, группа, РК1, РК2, итог. Посчитай средний итог по группе и отметь, у кого итог ниже 50.
   ```

3. Попросите выгрузить результат:

   ```
   Сделай из этого файл Excel.
   ```

## Ещё идеи

- Скриншот ошибки на компьютере → «Что это значит и как исправить?»
- Фото объявления на английском → «Переведи на русский и казахский».
- Фото доски после занятия → «Оформи как конспект».

## Важно

Проверяйте распознанные цифры: на нечётком фото Claude может ошибиться. Не загружайте ведомости с реальными персональными данными в личный аккаунт.

## Проверьте себя

- [ ] Claude правильно распознал все строки
- [ ] Средний итог совпадает с моим расчётом
