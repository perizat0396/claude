# 01 · Инкогнито-чат

**Бесплатный аккаунт: ✅ доступно** · ⏱ 3 минуты

## Зачем

Иногда нужно спросить что-то разовое или личное, и не хочется, чтобы это осталось в истории и повлияло на будущие ответы. Инкогнито-чат не сохраняется в списке чатов и не попадает в память Claude.

## Как включить

1. Откройте **новый чат** (не внутри проекта).
2. В правом верхнем углу нажмите значок **призрака** 👻.
3. Появится чёрная рамка и надпись «Incognito chat». Можно писать.
4. Чтобы выйти, нажмите **×** в правом верхнем углу.

## Задание

1. Откройте инкогнито-чат и напишите:

   ```
   Придумай 5 вариантов вежливого отказа коллеге, который просит взять его пары на этой неделе.
   ```

2. Закройте чат крестиком.
3. Откройте список чатов слева. Этого разговора там нет.

## Важно знать

- Закрытый инкогнито-чат восстановить нельзя. Скопируйте нужное **до** закрытия.
- В проектах инкогнито не работает: значка призрака там нет.
- Инкогнито не делает чат анонимным для организации и не отменяет правила безопасности. Персональные данные вставлять всё равно нельзя.
