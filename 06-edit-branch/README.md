# 06 · Ветки разговора

**Бесплатный аккаунт: ✅ доступно** · ⏱ 5 минут

## Зачем

Если ответ не устроил, не нужно писать «нет, я имел в виду другое» несколько раз подряд. Каждое такое сообщение тратит лимит и запутывает разговор. Лучше исправить сам вопрос: Claude ответит заново, а старый вариант сохранится в отдельной ветке.

## Как это работает

1. Наведите курсор на **своё** сообщение (на телефоне — нажмите на него).
2. Нажмите **карандаш (Edit)**.
3. Измените текст и отправьте.
4. Под сообщением появятся стрелки **‹ 1/2 ›** для переключения между вариантами.

## Задание

1. Напишите:

   ```
   Напиши поздравление коллеге с днём рождения.
   ```

2. Отредактируйте это же сообщение:

   ```
   Напиши короткое поздравление коллеге-преподавателю с 60-летием, тёплое, без пафоса, 3 предложения.
   ```

3. Переключитесь стрелками между вариантами и выберите лучший.

## Ещё приём

Кнопка **Retry (↻)** под ответом Claude даёт другой вариант на тот же вопрос. Удобно для заголовков и названий.
