# 12 · Критик своего ответа

**Бесплатный аккаунт: ✅ доступно** · ⏱ 5 минут

## Зачем

Первый ответ ИИ не всегда лучший. Попросите Claude найти слабые места: в своём ответе или в вашем тексте. Это заметно повышает качество писем, расчётов и аргументов.

## Задание

1. Откройте файл [`chernovik-pisma.md`](chernovik-pisma.md) и вставьте текст в чат.
2. Напишите:

   ```
   Проверь это письмо как строгий редактор: найди ошибки, неясные места, лишнее и что может вызвать раздражение у получателя. Сначала список проблем, потом исправленный вариант.
   ```

3. Затем попросите Claude проверить себя:

   ```
   Перечитай свой исправленный вариант. Все ли даты и цифры совпадают с исходником? Что ещё можно убрать?
   ```

## Подсказка

В черновике есть минимум 5 проблем: противоречие в датах, неверное число, отсутствие сути в начале, канцелярит и нет контакта для вопросов. Найдёт ли Claude их все?

## Универсальная фраза

```
Проверь свой ответ: найди ошибки, слабые аргументы и что я упустил.
```

## Проверьте себя

- [ ] Claude нашёл противоречие в датах
- [ ] Исправленное письмо короче исходного
