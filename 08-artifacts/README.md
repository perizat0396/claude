# 08 · Интерактивный тест из лекции

**Бесплатный аккаунт: ✅ доступно (артефакты)** · ⏱ 10 минут

## Зачем

Claude умеет делать не только текст, но и работающие мини-приложения: тесты, карточки для запоминания, калькуляторы, тренажёры. Они открываются прямо в чате, и ссылкой можно поделиться со студентами.

## Задание

1. Откройте файл [`lekciya-phishing.md`](lekciya-phishing.md), скопируйте текст или прикрепите файл в чат.
2. Напишите:

   ```
   Сделай по этой лекции интерактивный тест из 10 вопросов. После каждого ответа показывай, правильно или нет, и короткое пояснение. В конце покажи результат в процентах.
   ```

3. Пройдите тест сами.
4. Попросите доработать:

   ```
   Добавь кнопку «Пройти заново» и перемешивай вопросы при каждом запуске.
   ```

5. Нажмите **Share / Поделиться**, чтобы получить ссылку.

## Ещё идеи

- «Сделай карточки для запоминания терминов из этого текста».
- «Сделай калькулятор итоговой оценки: РК1 30%, РК2 30%, экзамен 40%».
- «Сделай тренажёр: показывай фото-описание письма, студент решает, фишинг это или нет».
