# 04 · Личные настройки

**Бесплатный аккаунт: ✅ доступно** · ⏱ 5 минут

## Зачем

Если вам каждый раз приходится писать «отвечай короче» или «без англицизмов», задайте это один раз в настройках профиля. Эти пожелания будут учитываться во всех чатах, даже в инкогнито.

## Как настроить

**Settings → Profile** → поле с вопросом, какие ответы вы предпочитаете (personal preferences).

## Задание

1. Откройте настройки профиля и вставьте в поле предпочтений:

   ```
   Пиши по-русски, просто и без канцелярита. Начинай с главного. Если пишешь на казахском, образовательную программу называй «білім беру бағдарламасы» (БББ).
   ```

2. Сохраните.
3. В новом чате попросите:

   ```
   Напиши объявление о переносе консультации на пятницу, 15:00, ауд. 214.
   ```

4. Сравните с тем, как Claude отвечал раньше.

## Чем отличается от памяти

| | Настройки профиля | Память |
|---|---|---|
| Кто пишет | Вы сами, один раз | Claude по ходу чатов |
| Для чего | Стиль и формат ответов | Факты о вас и ваших задачах |
| Работает в инкогнито | Да | Нет |
