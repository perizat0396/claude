# 02 · Проекты

**Бесплатный аккаунт: ✅ до 5 проектов** · ⏱ 10 минут

## Зачем

Если вы постоянно работаете с одними и теми же документами (положения, шаблоны, рабочая программа), не загружайте их в каждый чат заново. Положите их в проект один раз. Каждый новый чат в проекте будет знать эти материалы и вашу инструкцию.

## Как создать

1. В боковой панели слева выберите **Projects / Проекты** → **Create project**.
2. Дайте название, например «Учебный отдел».
3. В блоке **Project knowledge** загрузите файлы.
4. В блоке **Instructions** напишите, как Claude должен отвечать в этом проекте.

## Задание

1. Создайте проект «Практикум ВКУ».
2. Загрузите в него файл [`polozhenie-primer.md`](polozhenie-primer.md) из этой папки.
3. В инструкции проекта напишите:

   ```
   Отвечай только на основе загруженного положения. Указывай номер пункта. Если ответа в положении нет, так и скажи.
   ```

4. Откройте в проекте новый чат и спросите:

   ```
   Сколько раз студент может пересдать экзамен и в какие сроки?
   ```

5. Откройте **ещё один** новый чат в том же проекте и спросите:

   ```
   Что делать студенту, который пропустил экзамен по болезни?
   ```

Claude ответит в обоих чатах со ссылкой на пункты, хотя файл вы загрузили один раз.

## Ожидаемый результат

- Ответ про пересдачи ссылается на п. 4.2 и 4.3.
- Ответ про болезнь ссылается на п. 5.1.
