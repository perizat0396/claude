# Практикум: 12 лайфхаков Claude

**ВКУ им. С. Аманжолова · Цифровой офис · 2026**

Здесь практическая часть к инфографике «Claude: 12 лайфхаков». Каждый лайфхак — отдельная папка: зачем он нужен, пошаговое задание на 5–10 минут и учебные файлы.

Всё работает на **бесплатном аккаунте** (Free). Где у бесплатного аккаунта есть ограничение, это отмечено.

## С чего начать

1. Откройте [claude.ai](https://claude.ai) или приложение Claude на телефоне.
2. Войдите через Google или почту. Бесплатного аккаунта достаточно.
3. Выберите любой лайфхак ниже и выполните задание.

## Что есть в бесплатном аккаунте

Входит: веб-поиск, артефакты, создание документов и презентаций, память, проекты (до 5), голосовой режим, инкогнито, загрузка файлов и фото.

Есть ограничение на количество сообщений. Когда лимит закончится, Claude покажет время, когда можно продолжить. Совет: пишите одно подробное сообщение вместо пяти коротких.

Только в платных тарифах: модель Opus, режим Research, Claude in Chrome, неограниченное число проектов.

## Безопасность

- Не вставляйте ИИН, номера карт, пароли и персональные данные студентов и сотрудников.
- Служебные документы загружайте только в аккаунт, утверждённый университетом.
- Цифры, даты, ссылки на законы проверяйте по первоисточнику.
- Учебные файлы в этом репозитории вымышлены: имена и данные придуманы для практики.
