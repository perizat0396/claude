# 05 · Пусть сначала спросит

**Бесплатный аккаунт: ✅ доступно** · ⏱ 5 минут

## Зачем

Короткий запрос даёт усреднённый ответ. Длинное ТЗ писать долго. Решение: попросите Claude самому задать вопросы. Он уточнит то, о чём вы бы забыли написать.

## Задание

1. Напишите:

   ```
   Мне нужен план открытого занятия. Прежде чем отвечать, задай мне 5 уточняющих вопросов. Задавай их списком, я отвечу одним сообщением.
   ```

2. Ответьте на вопросы одним сообщением, например: «1) информатика 2) 1 курс 3) 50 минут 4) тема — циклы 5) есть проектор».
3. Получите план.

## Приём «роль + читатель + формат»

Добавляйте в запрос три вещи:

- **Кто вы для Claude:** «Ты методист», «Ты редактор»
- **Кто будет читать:** «для студентов 1 курса», «для ректората»
- **Какой формат:** «до 80 слов», «таблица», «5 пунктов»

Попробуйте:

```
Ты методист. Напиши объявление для студентов 1 курса о записи на элективы: до 80 слов, без канцелярита, на казахском и русском.
```

## Проверьте себя

- [ ] Claude задал вопросы до ответа
- [ ] Итоговый план точнее, чем при коротком запросе
