# 10 · Поиск с источниками

**Бесплатный аккаунт: ✅ доступно** · ⏱ 5 минут

## Зачем

Знания модели ограничены датой обучения. Для свежих новостей, правил, цен и расписаний Claude ищет в интернете. Главный приём: всегда просите ссылки, чтобы проверить каждый факт.

## Как включить

Кнопка настроек инструментов в поле ввода (значок ползунков или **+**) → включите **Web search**.

## Задание

1. Напишите:

   ```
   Найди актуальные требования к оформлению списка литературы по ГОСТ для курсовых работ. Дай краткую памятку с примерами и ссылку на источник к каждому пункту.
   ```

2. Откройте 2–3 ссылки и сверьте, что написано в источнике.
3. Попросите сравнение:

   ```
   Сравни бесплатные сервисы для проверки текста на заимствования, доступные в Казахстане. Таблица: название, лимиты, язык, ссылка.
   ```

## Как проверять ответы

- Источник официальный? (сайт министерства, вуза, производителя)
- Дата публикации свежая?
- Факт в ответе совпадает с текстом по ссылке?
